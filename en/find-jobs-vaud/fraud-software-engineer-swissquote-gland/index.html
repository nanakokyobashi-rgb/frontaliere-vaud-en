Full description

Operating within the First Line of Defence, the Fraud Soft ware Engineer serves as the core technical builder for the Anti-Fraud & Financial Crime squad. Working directly alongside the Squad Lead and Data Scientists , this role bridges analytical fraud detection and full-stack software execution. You will own the technical evolution of the back-office platforms on which anti-fraud and AML services run, develop and deploy internal front-end screens when new operational workflows are needed, and build robust Python backend services and API integrations. This is a high-ownership, hands-on engineering and data role for a pragmatic problem-solver who unblocks operational bottlenecks, thrives during live incident response, and focuses on shipping working solutions.

Key Responsibilities

  • Back-Office Service Evolution: Modify, extend, and maintain the internal back-office platforms and case-management systems supporting daily anti-fraud and AML operations.
  • Python Backend & Rules Execution: Design, write, and deploy clean, production-grade Python services to execute real-time transaction monitoring rules, automated blocking workflows, and dynamic risk-scoring logic.
  • System Reliability & Optimization: Monitor technical health across fraud services and data pipelines, proactively resolving latency issues, data flow failures, and operational bottlenecks.
  • Internal Screen Development: Build, iterate, and deploy lightweight, intuitive front-end screens and web interfaces (e.g. , alert triage views, manual review dashboards, and rule-configuration panels) whenever operational teams require new UI capabilities.
  • User Acceptance Testing (UAT) & Feedback Loops: Partner directly with fraud investigators, Customer Care, and Compliance to translate operational pain points into rapid UI/UX improvements and support UAT cycles.
  • Service & Vendor Integrations: Build and maintain API integrations connecting core banking/payment rails, internal microservices, third-party fraud prevention vendors, and threat intelligence feeds (such as OpenCTI).
  • Database & Search Engineering: Design, optimize, and maintain queries and schemas across relational and non-relational databases as well as search/telemetry engines (SQL, ES|QL).
  • Forensic Querying & Pattern Discovery: Execute deep-dive data extraction and forensic analysis using Python, SQL, and ES|QL to investigate complex fraud typologies, web traffic anomalies, and high-value incidents.
  • Productionizing Detection Models: Collaborate closely with the Fraud Officers and Data scientists to integrate machine learning models, feature pipelines, and threshold adjustments into live production environments.
  • Operational Reporting Support: Automate data feeds and technical metrics powering weekly/monthly KPI and KRI dashboards.
  • Rapid Emergency Execution: Act as a frontline technical responder during critical fraud incidents (eg, Account Takeover or APP fraud spikes), implementing urgent backend rule updates, hotfixes, or blocking criteria under tight timelines.
  • Audit-Ready Documentation: Maintain clear technical documentation covering architecture changes, API integrations, system logic, and post-incident root-cause analyzes to meet internal governance and regulatory audit standards.

Experience & Background

  • 5+ of hands-on experience in software engineering, backend/full-stack Python development, or technical data engineering—ideally within banking, fintech, payments, or financial crime/fraud operations.
  • Proven track record modifying existing legacy or internal back-office systems while shipping new end-to-end features in an agile squad environment.

Core Technical Skills

  • Strong Python Engineering (Mandatory): Advanced proficiency in Python for backend service development, API consumption/creation, automation scripting, and large-scale data manipulation.
  • Data & Querying Mastery (Mandatory): Strong command of SQL and experience with log/telemetry querying (such as Elastic Stack / ES|QL), alongside solid working knowledge of relational and non-relational databases.
  • Backend & Web Frameworks: Practical experience building and deploying web services and APIs using Python frameworks
  • Front-End Capabilities: Ability to develop and deploy functional front-end screens using modern web technologies (HTML/CSS, JavaScript/TypeScript, React,or Python-based web frameworks) when operational interfaces are required.
  • DevOps & Engineering Hygiene: Familiarity with Git, CI/CD pipelines, containerization (Docker), automated testing, and debugging production web traffic and network payloads.
  • Analytics & Visualization: Experience extracting actionable insights from complex datasets and familiarity with BI tools such as Tableau or Power BI.
  • Solution-Oriented Builder: A pragmatic, can-do engineering mindset—focused on finding compliant, workable paths forward.
  • High Ownership & Execution Bias: Self-starter who takes end-to-end accountability from technical scoping and coding through deployment, monitoring, and iteration.
  • Analytical Rigor: Natural curiosity for dissecting data anomalies, understanding adversarial fraud mechanics, and tracing root causes across complex systems.
  • Composure & Clear Communication: Able to stay calm and decisive during live fraud incidents while translating technical trade-offs clearly for non-technical stakeholders across Operations, Risk, and Compliance.
